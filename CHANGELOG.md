# Changelog

All notable changes to Better Arrows will be documented here.

## [1.0.2]
- Added broken arrow items for bent and tip-broken variants.
- Added item-break sound when arrows shatter on very hard blocks.
- Added material-based impact sounds.
- Added water slowdown that lingers for a short time after contact.
- Added in-game config switches for material sounds and water slowdown.
- Slime blocks launch arrows farther.
- Honey blocks absorb arrows without ricochet.
- Wood and wood-like blocks keep vanilla behavior.
- Stone and resistant blocks ricochet with reduced force.
- Obsidian and bedrock always break arrows.

## [1.0.1]
- Added block-based ricochet behavior.
- Added arrow recovery with loss on entity deaths.

## [1.0.0]
- Initial stable release.
