# 🎯 Better Arrows

A Minecraft mod that improves arrow mechanics.

## ✨ Features
- Arrow pickup system
- Ricochet mechanics
- Special interactions with blocks

## ⚠️ Status
Beta version – may contain bugs

## 📦 Installation
1. Install NeoForge (Minecraft 1.21.1)
2. Download the mod `.jar`
3. Place it in your `mods` folder

## 🧪 Requirements
- Minecraft 1.21.1
- NeoForge 21.x
